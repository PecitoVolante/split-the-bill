# SplitBill

移动端多人消费记账和平账 PWA。

## 功能

- 自定义参与人
- 消费默认平摊，也支持按权重调整比例
- 每笔消费支持不同付款人和不同币种
- 消费入账时自动获取到记账货币的汇率，失败时可手动输入
- 历史消费可编辑金额、说明、币种、付款人、分摊和汇率
- 平账时生成最少转账方案，并支持每个付款人自定义付款币种
- 支持分享或导出 PDF 账单总览、消费明细和基础平账方案
- 数据保存在当前设备浏览器本地

## 本地预览

用任意静态服务器打开项目根目录即可，例如：

```bash
python3 -m http.server 4173
```

然后访问：

```text
http://127.0.0.1:4173
```

## GitHub Pages

这是纯静态 PWA，可直接部署到 GitHub Pages。部署后用手机浏览器打开网址，并添加到主屏幕即可像手机应用一样使用。
